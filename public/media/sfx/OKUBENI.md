# Ses efekti kütüphanesi

Videolarda kullanılacak **gerçek, profesyonel ses efektlerini** buraya koy (ya da panelde "Video üret" penceresinden yükle).
Alt klasör adı sesin kategorisidir. Dosya adını açıklayıcı ver (ör. `whoosh-yumusak.wav`, `deklansor-eski-kamera.mp3`): ajan sesleri duyamaz, adından ve süresinden anlar.
"Ses kütüphanemi kullan" seçiliyken ajan bu sesleri kullanır; "Serbest" seçiliyken bu klasör hiç dahil edilmez.

Desteklenen dosyalar: .wav .mp3 .ogg .m4a .flac .aac

| Klasör        | Ne koymalı                                              |
| ------------- | ------------------------------------------------------- |
| whoosh        | Klasik geçiş "vuuş" sesleri (sahne geçişleri)          |
| swoosh        | Kısa, hızlı hava geçişleri (yazı/grafik girişi)        |
| shutter       | Fotoğraf makinesi deklanşörü                            |
| keys          | Klavye / daktilo tuş sesleri (daktilo animasyonları)   |
| click         | Arayüz / fare tıkı                                      |
| impact        | Hafif, alçak "bum" vurgu sesi                           |
| pop, ding, riser, transition, camera, paper, money, notification | İsteğe bağlı; sadece buraya dosya koyarsan kullanılır |


Telifsiz ses bulmak için: Pixabay Sound Effects, Mixkit, Freesound (CC0 filtresiyle).
Lisansını kontrol ettiğin sesleri koy.
